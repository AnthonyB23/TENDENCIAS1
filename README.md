# 🧩 Proyecto TENDENCIAS1  
## Web Service con Node.js y Frontend en JavaScript

---

## ⚙️ BACKEND

- Inicializar proyecto Node:  
  `npm init`

- Ejecutar el servidor principal (index.js):  
  `node index.js`

- Instalar Express (Framework Minimalista - Manejar rutas GET, POST, etc):  
  `npm install express`

- Instalar CORS (Middleware - Permitir o bloquear solicitudes de otros orígenes):  
  `npm install cors`

---

## 🎨 FRONTEND

- Para instalar cualquier dependencia al proyecto (aumentar nombre):  
  `npm install`

- Para ejecutar el entorno de desarrollo del frontend:  
  `npm run dev`
